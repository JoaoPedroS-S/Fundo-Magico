# 🎨 **Fundo Mágico** - Projeto de Geração de Fundos com IA

**Descrição**  
O projeto **"Fundo Mágico"** permite gerar backgrounds personalizados com base em uma descrição fornecida pelo usuário. Utiliza a API do **n8n** para gerar HTML e CSS de fundos dinâmicos, com transições suaves entre imagens e a possibilidade de aplicar degradês. A animação é complementada por sons de fundo que aumentam a imersão do usuário.

---

## 🚀 **Funcionalidades**

- **✨ Geração de fundos dinâmicos** com IA (utilizando a API do n8n).
- **🌈 Transição suave** entre diferentes imagens de fundo.
- **🎨 Efeito degradê mágico** que surge após a imagem final aparecer.
- **🔊 Sons** de fundo (um som ao início e outro ao finalizar o processo).
- **🖥️ Código HTML e CSS gerado** pela IA que é exibido em tempo real.
- **💾 Armazenamento persistente** de código (usando `localStorage`), permitindo visualizar os resultados anteriores até que o usuário envie uma nova descrição.

---

## 🧰 **Tecnologias Utilizadas**

- **HTML5** – Estrutura das páginas
- **CSS3** – Estilização visual e responsividade
- **JavaScript** – Funcionalidades dinâmicas e interatividade (caso aplicável)
- **n8n** – Geração automatizada de fundos com IA via Webhook

---

## 🎯 **Objetivos**

- **🎨 Criar um projeto visualmente atrativo** com efeitos dinâmicos de fundo.
- **🚀 Praticar interatividade e animações** usando JavaScript e CSS.
- **📡 Integrar com a API do n8n** para geração de código dinâmico e personalização do fundo.
- **📦 Gerar HTML/CSS automaticamente** e aplicá-los em tempo real no site.

---

## 🦸‍♂️ **Funcionalidades Principais**

### **Geração Automática de Fundos**
O usuário pode descrever um fundo, e a IA gera automaticamente um fundo dinâmico com base na descrição fornecida. O código HTML e CSS gerado é exibido na interface.

### **Transição Suave**
As imagens de fundo são trocadas suavemente, com transições animadas entre elas. Isso inclui a utilização de um **degradê mágico** após a imagem final aparecer.

### **Som e Animação**
São tocados sons ao longo do processo, aumentando a imersão, com uma animação de fade-in quando a imagem final é exibida.
